The scope remains layer-by-layer static decomposition. No payload, Lua,
factory, metatable, application or network code is executed. Demo/ESP files
are untouched. The host is not claimed to be physically air-gapped.

## Reproduction

```powershell
python tools/promotion_auditor.py
python -m unittest discover -s tools
luac -p AdnHub.lua Loader.lua
```

backing bytes. It parses the requested tracked Phase15 diagnostic Markdown

duplicate or stale rows fail closed; prose is never interpreted as commands.
Generated detailed proofs and the site-indexed table are local ignored files:
`output/phase16/promotion-proofs.json` and `static-string-table.json`.
