# 🥚 Adonis Hub (Adn Hub) - Steal an Egg

> **Futuristic Neo-Glassmorphism 2.0 UI Script Menu** dành cho trò chơi Roblox **Steal an Egg**.

---

## ✨ Điểm Nổi Bật Trong Thiết Kế

- **Futuristic Neo-Glassmorphism 2.0:** Nền kính mờ tối màu (Deep Dark Semi-Transparent Glass), kết hợp hiệu ứng viền phát sáng gradient xoay động (Rotating Glowing Stroke) giữa dải màu **Neon Cyan** & **Electric Purple**.
- **Header Sang Trọng:** Tên hiệu **ADONIS HUB** với chữ kim loại chuyển sắc (Metallic Gradient), biểu tượng quả trứng neon và các nút điều khiển thu nhỏ (`—`), đóng (`✕`) có micro-interactions mượt mà.
- **Floating Pill Mode:** Khi thu nhỏ, cửa sổ tự động biến thành nút hình viên thuốc (*Floating Pill*) nhỏ gọn `🥚 ADN HUB`, tự do kéo thả bất kỳ đâu trên màn hình để mở lại.
- **Sidebar Navigation 7 Tabs:**
  - 🏠 **Trang chủ:** Thông tin hệ thống, tối ưu FPS & Boost Lag, liên kết cộng đồng.
  - 🥚 **Hack Trứng:** Tự động cướp trứng (Auto Steal), vận chuyển về Base, hút trứng từ xa (Silent Vacuum), thanh trượt cự ly (Egg Steal Range 0-100 studs), bộ lọc loại trứng, ESP hào quang trứng.
  - 🏃 **Mod Nhân vật:** Tùy biến tốc độ di chuyển (WalkSpeed), lực nhảy (JumpPower), Infinite Jump trên không và Noclip xuyên tường.
  - 🗺️ **Dịch chuyển:** Dịch chuyển tức thời tới ổ trứng trung tâm, khu vực trứng thần thoại, trở về Base an toàn.
  - 🛍️ **Shop Misc:** Tự động nâng cấp dung tích balo, mua giày tốc độ và nhận quà hàng ngày.
  - 🛡️ **Anti-Cheat:** Cơ chế bảo vệ Anti-Fling (chống bị hất văng), Anti-AFK (chống ngắt kết nối sau 20 phút), Ghost Mode ẩn danh.
  - ⚙️ **Cài đặt:** Phím tắt đóng/mở menu mặc định (`Right Control`), gỡ hoàn toàn script (`Unload UI`), khôi phục vị trí mặc định.
- **Hệ thống Notification Tích Hợp:** Khung thông báo trượt động với thanh trạng thái phát sáng tương ứng theo ngữ cảnh (Success, Info, Warning, Error).

## 🚀 Cách Chạy Script

Dán đoạn mã dưới đây vào bất kỳ Roblox Executor nào (Delta, Fluxus, Wave, Solara, Synapse Z, Hydrogen, Arceus X,...):

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/caubebietbuon/AdnHub/main/AdnHub.lua", true))()
```

Hoặc chạy file `Loader.lua`:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/caubebietbuon/AdnHub/main/Loader.lua", true))()
```
